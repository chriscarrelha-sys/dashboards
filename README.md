# dashboards
Interactive sales dashboards for financial advisors

## dossiers/
Self-contained, print-ready HTML case documents. Each file is standalone — no
external assets, no scripts beyond an inline `window.print()` handler — so it can
be opened offline, emailed, or exported to PDF from any browser. All four share a
letter-size `@media print` stylesheet with page-break guards.

**Carrelha v. Regions Bank** · Civil Action File No. 26SC-1103-B
State Court of Forsyth County, GA · Hon. T. Russell McClelland · Hearing Sept 21, 2026

| File | What it is |
| --- | --- |
| `case-26sc-1103-b-motion-to-strike.html` | Research dossier — attack pillars, conflict matrix, statutory authorities, case law |
| `case-26sc-1103-b-hearing-script.html` | Podium script — pre-hearing checklist, opening, three pillar arguments, cross-examination sequence, rebuttal, the ask, contingency scripts |
| `case-26sc-1103-b-exhibit-binder.html` | Master exhibit index plus printable tab dividers (one per page) |
| `case-26sc-1103-b-objections.html` | Objections to make, objections to expect, and a one-breath reference card |

### Verification status

The script, binder, and objections documents are built only from facts confirmed
in the filed Answer and Affirmative Defenses and in Plaintiff's written CFPB
response. Material that depends on documents not yet available — the Farr
affidavit, the filed Motion to Strike, and the loan ledger — is left as marked
placeholder slots rather than guessed at. Each file carries a verification banner
stating what is confirmed and what is not.
