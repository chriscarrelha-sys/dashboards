# Provenance of material in this directory

The **original** case documents for this matter live in the client's Google
Drive and were read in full there. They were **not** downloaded, modified,
renamed, moved, or deleted. Nothing in this repository is an original.

What is stored here are **verbatim extracts**: the specific passages relied on by
the specialist skills, copied without alteration from the originals. Each extract
is registered in `03-sources/source-manifest.csv` with its own `SRC-###` and a
`derived_from` pointer to the original's entry, so no citation can confuse an
extract for the whole document.

Each original's manifest row records its Drive file ID in `notes`, its
`access_status` (whether the whole document was readable), and its `ocr_status`.
`validate_matter_pack.py --hash-check` fingerprints the extracts in this
directory so that any later alteration of a working copy is detectable.

An extract is never a substitute for the original. Before any filing or reliance,
the original must be re-opened and the quotation re-checked.
